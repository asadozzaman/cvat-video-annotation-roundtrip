Reproducibility / local setup

Run it on your machine.

The complete experiment is a local Python and Docker workflow. The static showcase is generated from its verified outputs; it is not a substitute for the API test.

Python 3.10Docker ComposeCVAT 2.76.0

Step 01 / CVAT

Start the official local stack.

Keep CVAT’s checkout separate from this repository. The recorded run used release v2.76.0. Create a local CVAT account after the containers are ready.

PowerShell or Git Bash
git clone --depth 1 --branch v2.76.0 https://github.com/cvat-ai/cvat.git ../cvat-upstream-v2.76.0
cd ../cvat-upstream-v2.76.0
docker compose up -d
docker exec -it cvat_server python3 /opt/cvat/manage.py createsuperuser

Step 02 / Python

Install the pinned dependencies.

Run these commands from the mini-test repository. On Linux or macOS, activate with source .venv/bin/activate and copy the environment file with cp.

PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env

Step 03 / Credentials

Configure local authentication.

Edit .env with your local CVAT username and password, or a personal access token. The real file is ignored by Git. Use http://localhost:8080 unless your CVAT port differs.

.env example / placeholders only
CVAT_BASE_URL=http://localhost:8080
CVAT_USERNAME=your_local_username
CVAT_PASSWORD=your_local_password
CVAT_TOKEN=

Step 04 / Execute

Run, validate, build the site.

The orchestrator generates the video, creates two new tasks, uploads annotations, exports/imports, validates, generates visual evidence, and refreshes this static site’s data.

PowerShell or Git Bash
python scripts/run_demo.py
python scripts/validate_alignment.py
python -m http.server 8000 -d docs

Open http://localhost:8000 to preview the site locally. Each full run creates two new CVAT tasks and records their IDs in sample/output/run_state.json.
